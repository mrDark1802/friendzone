## 5. Message Processing & Third-Party AI Translation
**TRANSPARENCY NOTICE:** FriendZone is designed to eliminate cross-cultural language barriers by performing automated, real-time message translation.

### A. Data Flow for Message Translation
1. When a user sends a chat message, the original text payload (`contentOriginal`) is transmitted over a Transport Layer Security (TLS 1.3) encrypted WebSocket / HTTPS connection to the FriendZone backend server.
2. The server verifies whether the recipient requires translation based on their native language configuration (`nativeLanguage`).
3. **Cache Lookup:** The server checks an internal Redis cache and PostgreSQL `translation_cache` table for an existing translation matching the text hash.
4. **Third-Party API Execution:** If no cached translation exists, the text snippet is securely transmitted via HTTPS REST API to:
   * **Azure Cognitive Services Translator API** (Microsoft Corporation, hosted in Microsoft Azure East US region).
   * **MyMemory Translation API** (Translated SRL, fallback provider).
5. **Storage:** Both the original message and generated translation text are saved in our database to support chat history loading across browser sessions.

### B. Cryptography and Encryption Standard
* **Transport Encryption:** All data in transit between your browser, our servers, and third-party APIs is encrypted using industry-standard TLS 1.3 / HTTPS protocol.
* **End-to-End Encryption (E2EE) Status:** **FRIENDZONE DOES NOT CURRENTLY IMPLEMENT END-TO-END ENCRYPTION (E2EE).** Because real-time translation requires server-side processing and third-party API execution, message content passes through our application servers in plain text before database storage. You should not send sensitive financial credentials or passwords over chat.
* **AI Model Training Policy:** According to our service integration agreements, messages submitted to Microsoft Azure Cognitive Services Translator API are processed strictly in-memory for translation and are **not** used by Microsoft to train foundation AI models.

## 10. Data Retention Policy
We store personal information only as long as necessary to fulfill service functions:
* **Active User Profile:** Retained until account deletion.
* **Chat Messages & Translations:** Retained in our database while the active conversation exists.
* **Session Records (`user_sessions`):** Expired sessions are purged after 30 days or immediately revoked upon user logout.
* **Translation Cache (`translation_cache`):** Text hash translations are stored permanently to eliminate redundant third-party API calls.
* **Audit & Safety Reports:** Moderation reports are retained for up to 12 months for compliance auditing.

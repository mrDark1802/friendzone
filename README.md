# FriendZone 💬

A modern real-time chat application built with:

## Frontend

- React
- Vite
- Tailwind CSS

## Backend

- Node.js
- Express.js
- PostgreSQL
- Prisma
- Socket.IO

## Features

- JWT Authentication
- Real-Time Messaging
- Group Chats
- Online Status
- Typing Indicator
- File Sharing
- Read Receipts
